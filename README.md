# 📊 Sales Intelligence & Profit Prediction System

An end-to-end Data Science and Machine Learning project that analyzes retail sales data, identifies business insights, and predicts transaction-level profit using a Gradient Boosting Regression model.

## 🚀 Project Overview

This project combines:

- Exploratory Data Analysis
- Business analytics
- Customer segmentation
- Feature engineering
- Machine learning
- Model evaluation
- Feature importance analysis
- Model serialization
- Streamlit deployment

The final application allows users to enter transaction details and receive an estimated profit prediction.

---

## 🎯 Objectives

The main objectives of this project are to:

- Analyze sales and profitability patterns
- Identify the impact of discounts and product categories
- Analyze regional and customer-level performance
- Build machine learning models for profit prediction
- Compare multiple regression algorithms
- Tune and evaluate the models
- Deploy the final model through Streamlit
